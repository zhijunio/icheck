# 爱巡店

爱巡店是一个面向门店场景的 AI 巡检 Demo。用户可以根据自然语言生成巡检模板，按门店区域执行巡检，同时使用区域级 AI 图片识别和巡检项人工图片取证，最后由巡检人确认结果并形成整改闭环。

当前项目是前端 Demo，数据保存在浏览器 `localStorage` 中。巡检模板生成、巡检图片分析、结果总结、整改建议和模板质量检查均通过服务端接入 AI Router。

## 功能

- 根据文字描述生成巡检模板
- 上传巡检模板手稿生成可编辑模板
- 按区域管理巡检项目
- 编辑、保存和删除自定义巡检模板
- 基于模板创建巡检任务并分配执行人
- 支持默认排序、用户常用路径和 AI 推荐路径
- 每个巡检任务同时支持区域级 AI 图片识别和按巡检项手动上传
- 支持先批量上传区域图片，再统一点击 AI 分析；新增图片后可重复分析
- 区域级 AI 图片识别自动关联图片与巡检项目，并辅助判断项目是否合格及说明原因
- 巡检项人工图片取证每个项目最多上传 5 张图片，不调用 AI，由巡检人直接判断
- 巡检人逐项确认最终结果
- 不合格项目自动生成整改任务
- AI 根据巡检项目要求和现场照片生成整改建议（包括整改优先级、完成时限和验收标准）
- AI 对比整改前后图片，辅助判断是否达到验收标准
- 查看巡检总结和 AI 分析
- 结果页展示总计花费时间，并从巡检效率、实际路径、巡检问题和改进建议等维度总结
- 导出 CSV 和打印巡检结果
- 整改状态跟踪

## 快速开始

### 环境要求

- Node.js
- npm

### 安装依赖

```bash
npm install
```

### 配置 AI

巡检模板的文字描述生成通过服务端 Route Handler 调用 AI Router。启动前设置服务端环境变量：

```bash
export AI_API_KEY="替换为你的 DeepSeek API Key"
export AI_BASE_URL="https://api.deepseek.com"
export AI_MODEL="deepseek-v4-pro"
```

API Key 不要写入代码，也不要使用 `NEXT_PUBLIC_` 前缀。AI Base URL、模型和 API Key 均只在服务端通过环境变量读取。项目通过 DeepSeek 的 OpenAI 兼容接口 `${AI_BASE_URL}/chat/completions` 发起请求。

### 启动开发环境

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

如果端口被占用，Next.js 会自动使用其他可用端口。

### 生产构建

```bash
npm run build
npm run start
```

## 使用流程

1. 进入“模板”，输入门店类型、巡检场景、区域和检查重点。
2. 点击“一键生成巡检模板”，检查并修改生成的区域和巡检项目。
3. 保存模板后进入“任务”，创建巡检任务并选择门店、场景、执行人和执行时间。
4. 进入执行页面，选择任意区域。先上传本区域图片，再点击“开始 AI 分析”统一分析，或在每个巡检项下单独上传图片。
5. AI 会将有证据的区域图片分配到对应巡检项；完全无关的图片不会强行分配。手动上传的图片不会调用 AI。
6. 确保每个巡检项都有图片证据后，由巡检人逐项确认“合格”或“不合格”。
7. 所有区域完成后，系统生成本次巡检结果。
8. 不合格项目会进入“整改”，可填写整改说明、上传整改图片并更新整改状态。

巡检区域可以自由选择，不要求按照系统推荐顺序执行。排序方式只用于辅助规划现场路线。

## 项目结构

```text
src/app/
├── api/template/generate/     # 服务端 AI Router 代理
├── api/inspection/analyze/    # 服务端图片分析代理
├── api/results/analyze/       # 服务端巡检结果分析代理
├── api/rectification/suggest/ # 服务端整改建议代理
├── api/rectification/verify/  # 服务端整改前后图片对比验收代理
├── api/template/review/       # 服务端模板质量检查代理
├── demo-data.ts              # Demo 模板、区域排序和示例数据
├── demo-task-context.tsx     # Demo 状态、localStorage 持久化和任务进度
├── templates/                # 巡检模板列表和编辑
├── tasks/                    # 任务列表和巡检执行
├── results/                  # 巡检结果、AI 总结和导出
├── rectifications/           # 整改项目跟踪
├── layout.tsx                # 全局布局和导航
└── page.tsx                  # 首页
```

## Demo 边界

当前版本用于产品流程演示：

- 巡检模板文字生成通过服务端 DeepSeek API 调用环境变量 `AI_MODEL` 指定的模型。
- 巡检模板手稿识别通过服务端 AI Router 发送压缩后的手稿图片进行识别。
- 区域 AI 图片识别下，巡检图片关联和巡检项目合格判断通过服务端 DeepSeek API 调用环境变量 `AI_MODEL` 指定的视觉模型；按巡检项手动上传的图片不调用图片 AI。
- 巡检结果总结、基于巡检项目要求和现场照片的整改建议、模板质量检查通过服务端 DeepSeek API 调用环境变量 `AI_MODEL` 指定的模型；AI 不改变巡检人的最终判定。
- 提交整改完成时将整改前后图片发送给 AI，对比验收标准并保存通过、不通过或无法判断的验收建议；整改状态由用户的完成操作确认，AI 不替代人工决定。
- AI 推荐路径使用基于区域名称和规则的 Demo 逻辑。
- 数据仅保存在当前浏览器的 `localStorage` 中。
- 任务页支持加载一条明确标记为“演示案例”的预置任务，用于比赛现场快速展示完整流程。
- 图片会在浏览器端压缩后保存，清理浏览器数据会导致 Demo 数据丢失。
- 当前没有独立后端服务、用户认证和真实数据库，仅使用 Next.js Route Handler 代理 AI 请求。
